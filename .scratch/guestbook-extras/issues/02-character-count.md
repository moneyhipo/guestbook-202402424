# 02: 작성 폼 글자 수 표시

**What to build:** 방문자가 새 글을 쓸 때 메시지 입력칸 아래에 현재 글자 수가 `N / 1000`으로 보인다. 입력할 때마다 바뀌고, 등록에 성공하면 0으로 돌아간다. 색상 변화는 없다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 빈 폼에서 `0 / 1000`이 보인다
- [ ] 글자를 입력하면 숫자가 즉시 바뀐다
- [ ] 등록 성공 후 `0 / 1000`으로 초기화된다
- [ ] 수정 화면과 이름 칸에는 표시하지 않는다
