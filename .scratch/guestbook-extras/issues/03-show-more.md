# 03: 목록 더 보기 (5개씩)

**What to build:** 목록은 최신순으로 처음 5개만 보인다. 더 오래된 글이 남아 있으면 "더 보기" 버튼이 보이고, 누를 때마다 5개씩 아래에 이어진다. 보던 범위는 URL에 담겨서 새로고침이나 글 작성·수정·삭제 후에도 유지된다. "전체 글 (N)"은 계속 전체 개수를 보여준다.

- [x] 남은 글이 없으면 "더 보기"가 사라진다
