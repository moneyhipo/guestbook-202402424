# 05: 비밀번호 연속 실패 잠금

**What to build:** 한 글에 수정·삭제 비밀번호 시도가 5번 연속 틀리면 그 글은 5초 동안 잠긴다. 틀릴 때마다 남은 시도 횟수를 안내하고, 잠긴 동안에는 맞는 비밀번호도 거부하면서 남은 초를 안내한다. 성공하면 연속 실패가 초기화된다. 잠금은 글 단위이고, 글 보기와 좋아요에는 영향이 없다. 기존 배포 DB에는 필요한 컬럼이 자동으로 추가된다.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 틀리면 `비밀번호가 일치하지 않습니다. (남은 시도 N회)`가 보인다
- [ ] 5번째 실패에서 `비밀번호를 5회 틀려 5초간 잠겼습니다.`가 보인다
- [ ] 잠긴 동안에는 맞는 비밀번호도 `잠시 후 다시 시도하세요. (N초 남음)`으로 거부된다
- [ ] 5초가 지나면 맞는 비밀번호로 수정·삭제가 된다
- [ ] 성공 후에는 남은 시도가 다시 5회부터 시작된다
- [ ] 수정과 삭제가 같은 실패 횟수를 공유한다
- [ ] 다른 글은 영향을 받지 않는다
- [ ] 잠금 정책 모듈에 대한 테스트가 위 규칙을 검증한다
