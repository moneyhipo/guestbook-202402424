# 04: 좋아요

**What to build:** 모든 글에 좋아요 버튼과 좋아요 수가 보인다. 방문자는 비밀번호 없이 누를 수 있고, 한 브라우저에서 한 글에 한 번만 누를 수 있으며, 다시 누르면 취소된다. 누른 상태는 새로고침해도 유지된다. 좋아요 수는 0 아래로 내려가지 않는다. 기존 배포 DB에는 좋아요 수 컬럼이 자동으로 추가된다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 기존 글은 좋아요 0으로 보인다 (자동 마이그레이션)
- [ ] 누르면 즉시 +1이 되고, 버튼이 "눌림" 상태로 바뀐다
- [ ] 다시 누르면 -1이 되고 원래 상태로 돌아간다
- [ ] 새로고침 후에도 눌림 상태와 숫자가 유지된다
- [ ] 좋아요 수가 음수가 되지 않는다
